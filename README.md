# Cuti Online

Aplikasi pengajuan cuti (PWA) untuk PT Geopersada Mulia Abadi. Saat ini **mode demo**: data fiktif di browser, tanpa server.

- Demo: https://mrexcellearn.github.io/cuti-online/
- `web/`: PWA (index.html, tema.css, gaya.css, logika.js, mock.js, api.js, app.js, manifest, sw.js)
- `docs/api.md`: kontrak API (dipakai mock sekarang, Google Apps Script nanti)
- `tes/`: `node tes/logika.test.js`, `node tes/mock.test.js`, Playwright `tes/ui.test.js` + `tes/iframe.test.js` (server lokal port 8765 dari folder `web/`)

Akun demo: klik profil di halaman masuk (PIN 123456).
